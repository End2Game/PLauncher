# Roadmap

## 1.7.0 — Dependency and launch pipeline
Recursive required CurseForge dependencies, loader-aware launch metadata, expanded argument substitutions, and native extraction from vanilla and loader metadata.

## 1.8.0 — Launch compatibility validation
Compile and test matrix across supported Minecraft versions and Java runtimes; improve Mojang rule evaluation, loader-specific edge cases, and process/log handling.

## 1.9.0 — Authentication and updater
Microsoft refresh token, secure OS credential storage, non-blocking OAuth, signed/checksummed staged updater.

## 2.0.0 — Stabilization
Windows release pipeline, integration tests, full feature parity review, UX polish.
